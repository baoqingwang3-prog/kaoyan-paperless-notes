# 考研手写笔记无纸化：可复制提示词模板

这不是“拍张照，AI 就替你学完”的项目。

它只解决一件很实际的事：手写完不用再誊抄一遍。把值得复习的页面丢进待识别目录，运行一次入库，得到可搜索的 Markdown 笔记；草稿只归档，不浪费识别次数；看不清的字会单独标出来，复习时扫一眼原图即可。

仓库不提供作者的真实知识库和凭据，只提供一组可以直接交给 Cursor、Codex 或 Claude Code 的提示词。你可以让它们在自己的电脑上搭建、审计和验收同类流程。

## 最短使用方法

1. 先把 [00-一口气搭建.md](prompts/00-一口气搭建.md) 里的占位符改成你的知识库目录、科目和系统环境。
2. 把整段提示词交给本地编码 Agent 执行。
3. 如果你已经有半成品，按 `01 → 02 → 03 → 04 → 05` 分阶段使用，避免推倒重来。
4. 真正调用识别模型或写入 Notion 前，先确认费用、隐私和测试图片范围。

## 日常链路

```text
手写页/PDF → 待识别/<科目> → 一键入库 → Markdown 正文
                                      ├─ 回执：成功、失败、AI 次数、剩余数量
                                      └─ 可选：Notion 索引 + FSRS 到期复习

演算草稿   → 仅存档           → 不调用 AI，只保留原件
打字想法   → 速记命令         → 不调用 AI，直接写 Markdown
```

## 这套模板要求 Agent 守住什么

- 原纸面转写和 AI 纠错分层，AI 不得偷偷把错字“改对”后冒充原文。
- 形近字、连笔、涂改、遮挡和模糊处进入“转写可靠性”，完全看不清才写 `？`。
- 已知科目从目录取得，不让模型重复猜科目。
- 单张失败不影响整批；失败文件留在原处，下次可重跑。
- 默认限制每轮处理数量，避免一次误操作烧掉大量调用费。
- 同内容按大小和 SHA256 去重；同标题笔记自动使用 `-2`、`-3`，不覆盖旧笔记。
- 外部索引写入失败时回滚本轮新笔记，避免本地正文和索引半成功。
- 所有凭据只存在本机忽略文件中，仓库只保存配置示例。

## 公开版边界

本仓库没有作者的真实考研笔记、学校选择、目录结构、截图、Token、数据库 ID、代理地址、绝对本机路径、运行日志和验收原件。

OCR 不可能保证零错。最省时间的现实做法不是假装它百分之百正确，而是让不确定处足够醒目，只核对这些地方。
