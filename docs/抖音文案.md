# 抖音文案

## 口播版

我最近把考研手写笔记折腾成了一套无纸化流程。

不是那种“拍张照，AI 就替你学会了”的噱头。它真正省掉的是最烦的重复劳动：写完一页，再手动誊抄一遍、建文件夹、改标题、做索引。

现在我的用法很简单：值得复习的手写页扔进对应科目的文件夹，点一下入库，它会生成 Markdown 笔记；纯演算草稿只归档，不浪费识别次数。看不清的字和涂改会单独标出来，复习时只核对这些地方，不用整页重新看。

我也踩过坑，比如同名笔记被覆盖、同一张图换个名字又识别一遍、AI 偷偷把原文改“正确”。所以我没有直接公开自己的整个知识库，而是把搭建、审计、真实截图验收和最后冻结工具链的提示词整理成了模板。

想自己搭一套的，直接把 GitHub 里的提示词交给 Cursor、Codex 或 Claude Code，再把路径和科目换成自己的就行。

GitHub：https://github.com/baoqingwang3-prog/kaoyan-paperless-notes

工具搭好就停，别把考研变成开发比赛。最后真正涨分的，还是你写进去的内容。
