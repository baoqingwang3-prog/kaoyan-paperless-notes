# 提示词 00：从零搭建最小可用版

复制下面整段，先替换尖括号占位符。

```text
你是本地学习工作流工程师。请在我的现有知识库中搭建一套“考研手写笔记无纸化”最小可用流程，并完成离线测试。

环境：
- 系统：<Windows/macOS/Linux>
- 知识库根目录：<VAULT_ROOT>
- Markdown 工具：<Obsidian/其他>
- 科目短名：<例如 数二、英二、专业课>
- 可选索引：<Notion/不用>
- 可选复习调度：<FSRS/不用>
- Python：先探测现有可用解释器，不要擅自安装或卸载版本

目标日常动作只有四步：
1. 值得复习的图片或 PDF 放进“资料/待识别/<科目>/”。
2. 只想留底的演算草稿放进“资料/仅存档/”，不得调用 AI。
3. 运行一个明确的一键入口。
4. 查看当天回执；成功笔记进入“<科目>/知识点/”或“<科目>/错题/”，失败文件留在输入目录。

必须实现：
- 已知科目直接从输入目录取得，不能再让模型猜。
- 原始转写、转写不确定处、纸面涂改、结构化正文、AI 纠错、AI 补充必须分层保存。
- 识别模型不得修正、补全或润色纸面原文；完全看不清写“？”，能读但没把握则正常转写并列入“转写可靠性”。
- 支持常见图片和 PDF；临时文件无论成功失败都要清理。
- 默认每轮最多处理 10 个输入；上限同时约束总处理数和 AI 调用数。
- 使用操作系统级互斥锁，避免双击和计划任务同时处理同一批文件。
- 单张失败不得中断整批；失败和超额文件留在原目录。
- 归档前按文件大小和 SHA256 查重；同内容换文件名也不能重复付费识别。
- 同日期、科目、类型、标题冲突时生成“-2”“-3”，绝不覆盖旧笔记。
- 若可选外部索引写入失败，只回滚本轮新文件，不得删除旧笔记。
- 打字速记直接写 Markdown，不调用识别模型。
- 每轮生成 Markdown 回执，至少列成功、失败、实际 AI 调用数、仅存档数和剩余待处理数。
- 所有 Token、数据库 ID、代理和私有端点只从本机配置读取；真实配置进入 .gitignore，仓库仅保存占位示例。

执行规则：
1. 先只读检查现有目录、项目说明、Git 状态和测试，保留用户已有文件与修改。
2. 给出不超过 8 行的实施说明后直接实现，不要让我重复背景。
3. 采用最小改动，不搭建网页、数据库平台或多 Agent 常驻服务。
4. 不调用真实模型、不访问 Notion、不注册计划任务，除非我针对这一次动作明确授权。
5. 为核心行为写离线测试：科目路由、仅存档零 AI、上限、锁、失败隔离、哈希去重、同标题编号、外部索引失败回滚、速记零 AI。
6. 运行完整离线测试并报告“通过数/总数”、耗时、未验证项和关键文件。
7. 把日常使用说明写入知识库；不要生成周计划或改变我的学习目标。

完成标准：
- 一键入口存在且离线可运行。
- 核心测试全部通过。
- 真实凭据和真实笔记未进入新文件、测试输出或 Git。
- 清楚标明：本轮只是本地通过，真实 OCR、外部索引和计划任务仍待单独授权验收。
```
