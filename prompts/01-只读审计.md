# 提示词 01：先看现状，别急着重写

```text
请对当前“手写笔记 → Markdown/Obsidian → 可选 Notion/FSRS”流程做只读审计。

这一步禁止修改文件、安装依赖、调用真实识别模型、访问 Notion、注册计划任务、提交或推送 Git。

检查范围：
- 项目说明、目录结构、入口脚本、配置示例、识别 schema、渲染逻辑、测试和最近验收回执。
- 不读取或输出真实 Token；不得打印真实配置值。
- 不扫描与本项目无关的整个硬盘或整个知识库。

按真实学生每天的使用顺序检查：投放图片/PDF → 运行入口 → 识别 → 写 Markdown → 可选外部索引 → 归档 → 回执 → 到期复习。

重点验证：
1. 原文和 AI 意见是否真正分层。
2. 不确定读数和涂改是否可见。
3. 仅存档、速记是否保证零 AI。
4. 单张失败、并发运行和每轮上限是否安全。
5. 同内容换名是否重复识别；同标题是否覆盖旧笔记。
6. 外部索引失败时本地状态是否回滚一致。
7. 文档描述是否与代码一致。

能安全运行的非网络测试请实际运行。最后只输出：
- 一句话结论。
- 用户每天怎么用，不超过 8 行。
- 已经可靠的部分，注明代码/测试证据。
- 真正影响日常使用的问题，按严重程度排序。
- 最值得改的 3 项及最小验证方法。
- 现在没必要做的事。
- 明确区分“本轮确认”“历史文档声明”“当前无法证明”。
```
