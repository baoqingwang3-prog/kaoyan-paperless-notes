# 提示词 04：用一张真实截图验收

```text
现在进行一次真实截图端到端验收。只有我明确允许本次真实模型调用后才能开始；授权只覆盖这一张指定图片和这一次识别，不自动授权批量调用、计划任务或其他外部写入。

验收前先确认：
- 指定图片路径和科目。
- 预计调用次数上限。
- 是否允许写入可选外部索引；未明确允许时只验证本地链路。
- 图片不含不应发送给模型的个人信息。

执行：
1. 记录原图 SHA256、尺寸和输入位置。
2. 只运行一个受控入库进程，不并发启动第二个识别任务。
3. 记录真实调用次数、重试次数、耗时、退出码和生成文件。
4. 成功时核验 Markdown 正文、归档图哈希、回执和可选外部索引；失败时核验原图仍在输入目录。
5. 对照原图人工复核 transcription、uncertain_readings 和 handwriting_edits，不能只看程序返回成功。
6. 明确标出被模型改写、误读或漏掉的内容；只修证据确定的错误。

输出结论只能是：
- PASS：链路和转写均满足要求。
- PASS WITH REVIEW：链路成功，但存在已醒目标记、复习时仍需对照的模糊读数。
- FAIL：数据状态、识别忠实度或外部索引不满足要求。

回执必须区分程序成功、人工复核和未验证能力。不得把“进程启动”写成“验收完成”。
```
