# 提示词 05：最后修一下，然后去学习

```text
根据真实截图验收，只修已经被证据证明会影响日常使用的问题。不要借机扩展功能。

允许范围：
- 数据丢失、旧笔记覆盖、重复识别付费、科目入口不一致、失败回滚错误、文档与代码明显冲突。

禁止范围：
- 更换整套技术栈。
- 新建网站、移动端 App、复杂数据库或常驻多 Agent 系统。
- 为了追求“完全零人工核对”反复调用真实模型。
- 创建与考试得分无关的周报、看板和装饰性页面。
- 未授权的外部发布、计划任务注册或批量数据迁移。

每个修复必须有针对性回归测试。完成后运行完整非网络测试，报告通过数/总数、耗时和仍未验证的外部能力。

若测试通过且没有 P0 问题：
1. 写一份“本地通过 / 工具链冻结”回执。
2. 停止继续优化工具。
3. 用一句话告诉我真实日常动作：学完 → 投放 → 一键入库 → 核对不确定处 → 到期复习。
4. 提醒我回去学习，不再提出新的工程任务。
```
